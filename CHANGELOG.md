# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-05

### Added
- Core parsing engine for `chai-*` class names
- 8 utility modules: spacing, colors, typography, borders, layout, flexbox, sizing, effects
- Responsive variants (`chai-sm:`, `chai-md:`, `chai-lg:`, `chai-xl:`, `chai-2xl:`)
- Pseudo-class variants (`chai-hover:`, `chai-focus:`, `chai-active:`)
- Arbitrary value syntax (`chai-w-[300px]`, `chai-bg-[#ff6600]`)
- LRU cache for parsed class results
- MutationObserver for dynamic DOM updates
- Plugin system for custom utilities
- Deep-mergeable configuration
- Auto-initialization for `<script>` tag usage
- ESM, CJS, and IIFE builds
- Comprehensive test suite (83 tests)
- Interactive demo page
